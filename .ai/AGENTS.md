# Atlas — AI Context Pointer

`.ai/` is **no longer an authoritative project-state source**. The files that
previously lived here (context, architecture, rules, prompts, templates) were
obsolete or hollow and have been collapsed into this single pointer.

Use the Project Atlas authority model instead:

- **Current state:** `docs/ATLAS_STATE.md` (authoritative)
- **Future direction:** `docs/ROADMAP.md` (authoritative)
- **Permanent principles:** `docs/ATLAS_CORE.md`
- **Identity and purpose:** `docs/ATLAS_VISION.md`
- **Public entry point:** `README.md`
- **Historical material:** `docs/archive/`

Do not use obsolete `.ai` context files as current project instructions.

Atlas remains **model-independent**: external AI models are optional tools, not
Atlas's intelligence or identity.
